国家重点保护动物

国家重点保护野生动物：最初由中国原林业部和农业部根据《中华人民共和国野生动物保护法》的相关规定，共同指定并发布的一份由国家重点保护的珍贵，濒危野生动物名录。其中保护级别为一级二级，并且对水生，陆生动物作了具体划分 明确了由渔业，林业行政主管部门分别主管的具体种类。2021年2月5日，新国家重点保护野生动物名录正式公布，新增517种野生动物，大斑灵猫等43种列为国家一级野生保护动物 狼等474种列为国家二级保护野生动物。豺，长江江豚等65种由国家二级保护野生动物升为国家一级保护动物
